# Web Scraping – Page Title Extractor

A beginner-friendly Python project that extracts a webpage's title using `requests` and `BeautifulSoup` and saves it to a text file.

## Features
- Fetches webpage HTML using HTTP requests.
- Extracts the page title using BeautifulSoup.
- Saves the title to `title.txt`.

## Technologies Used
- Python
- Requests
- BeautifulSoup4

## Installation
Install the required libraries:

```bash
pip install requests beautifulsoup4
```

## Usage
Run the Python script:

```bash
python main.py
```

The extracted webpage title is saved in `title.txt`.

## Learning Goals
Practice HTTP requests, HTML parsing, and Python file handling.
